Autonomous ReAct Execution & Error Resilience Sequence
Traces an end-to-end iteration including circuit breaker verification, fallback routing, and token truncation recovery.
sequenceDiagram
    autonumber
    actor User as User / CLI
    participant Agent as FinancialResearchAgent
    participant Context as ContextManager
    participant LLM as Groq / Qwen LLM
    participant Parser as ResponseParser
    participant Registry as ToolRegistry
    participant Circuit as ToolCircuitBreaker
    participant Fallback as FallbackChainManager

    User->>Agent: run(query)
    Agent->>Context: allocate_budget(query, system_prompt)
    
    loop ReAct Iterations (Max 4-5)
        Agent->>LLM: complete(prompt, context)
        LLM-->>Agent: LLM Response (JSON / XML)
        Agent->>Parser: parse_response(raw_text)
        
        alt Tool Call Requested
            Parser-->>Agent: ParsedResponse(tool_name, arguments)
            Agent->>Circuit: check_state(tool_name)
            alt Circuit OPEN (Provider Outage)
                Circuit-->>Agent: CircuitBreakerOpenError
                Agent->>Fallback: execute_fallback(tool_name, arguments)
                Fallback-->>Agent: Degraded Result + Confidence Penalty
            else Circuit CLOSED / Normal
                Agent->>Registry: execute(tool_name, arguments)
                Registry-->>Agent: Observation Data
                Agent->>Circuit: record_success(tool_name)
            end
            Agent->>Context: append_observation(tool_name, result)
        else Final Answer Produced
            Parser-->>Agent: ParsedResponse(response_type="final", content)
            Note over Agent: Synthesis complete before iteration limit
        end
    end

    alt Final Synthesis Iteration
        Agent->>LLM: complete(synthesis_prompt, all_evidence)
        LLM-->>Agent: Complete Report Output
        Agent->>Parser: parse_response(report)
        Parser-->>Agent: Formatted Research Document
    end

    Agent-->>User: result {"status": "completed", "answer": ..., "tool_calls": [...]}
